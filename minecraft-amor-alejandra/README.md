# Aventura 8-bit para Alejandra ❤️

Sitio romántico inspirado en una aventura pixel-art tipo videojuego, creado desde cero para Anderson.

## Abrir en Visual Studio Code

1. Descarga o clona la carpeta del proyecto.
2. Abre la carpeta `minecraft-amor-alejandra` en Visual Studio Code.
3. Abre `index.html` con tu navegador o usa la extensión **Live Server**.

## Archivos

- `index.html`: estructura y textos.
- `styles.css`: diseño pixel-art y adaptación móvil.
- `app.js`: navegación, animaciones y sonidos.

## Compatibilidad

Diseñado para funcionar en Chrome, Edge, Firefox y navegadores móviles de Android/iPhone. No usa WebGL ni librerías pesadas.
