# Aventura Pixel — Camino hacia Alejandra ❤️

Juego original de plataformas 2D inspirado en la sensación de los clásicos de 8/16 bits, con arte propio dibujado por código.

## Incluye
- 3 niveles.
- Movimiento, salto y cámara lateral.
- Corazones coleccionables.
- Enemigos que se pueden derrotar saltando encima.
- 3 vidas.
- Puntuación.
- Checkpoints.
- Plataformas móviles.
- Pausa.
- Sonidos generados en el navegador.
- Controles de teclado y controles táctiles.
- Pantalla completa y soporte para Android/iPhone/PC.
- Final romántico con Alejandra.

## Controles
PC: A/D o flechas para moverse. W, flecha arriba o Espacio para saltar. P o Esc para pausar.

Móvil: botones ◀ ▶ y SALTAR.

## Abrir en Visual Studio Code
Abre la carpeta y ejecuta `index.html` con Live Server, o abre `index.html` directamente en el navegador.
